# Page override — Account (`/account`)

> Overrides `../MASTER.md` for the signed-in user's own console. Every action here targets **self** (`req.auth.sub`); nothing takes a user id.

- **Shell:** `StickyPageHeader` (title + subtitle + secondary "Sign out") → `AccountHero` → `SettingsNav` (rail ≥lg, chips below) + sections. Reuses the Settings kit (`SettingsSection`, `SettingsRow`, `SettingsNav`) so /account and /settings read as one family.
- **Hero:** identity (76px `PersonAvatar mode="auto"`, serif name, role pill in the role's own colour, branch + staff title chips, phone / email / member-since / last sign-in) + a **security score ring** (0–100, weights password-fresh 40 · ≤3 sessions 25 · email 20 · photo 15). Each checklist row is a button that scrolls to the section that fixes it. No strike-through on done items — it cuts through Lao vowel marks.
- **Stat row:** four `CardCount`s (signed-in devices · password age · actions 30d · permissions), each jumps to its section.
- **Sections (in order):** Profile (name/email editable, inline dirty footer — not the page-level StickySaveBar; phone/role/branch read-only with lock + "managed by an administrator") · Password (show/hide, 4-segment strength meter, requirements checklist driven by Settings ▸ `minPasswordLength`, "sign out other devices" switch default ON) · Devices & sessions (device-kind icon, online dot, "This device" badge, per-row revoke, "sign out all others"; destructive confirm dialogs) · Quick-login PIN (staff/admin only; dialog needs current password; blocks repeats/sequences) · Preferences (language + `AppearanceControls`, per-device) · Access (effective permissions grouped by module using `permissionGroups` icons/colours; modules without access listed dashed) · Activity (own audit trail, day-grouped timeline, keyset "show older").
- **Colour:** neutral surfaces; primary only on primary buttons, the active rail item and the current-device tile. Score ring uses success/warning/destructive tokens with a text level beside it (never colour alone).
- **Errors:** field-level `role="alert"` + `aria-describedby`; a wrong current password (401 `INVALID_CREDENTIALS`) is shown on the field and must never trigger the HTTP interceptor's refresh/logout.
- **API:** `GET /auth/me/overview`, `GET /auth/me/sessions`, `DELETE /auth/me/sessions/:id`, `POST /auth/me/sessions/revoke-others`, `GET /auth/me/activity?limit&before`, `PUT|DELETE /auth/me/quick-login-pin`, `PATCH /auth/me` (+`avatarUrl`), `POST /auth/change-password` (+`signOutOthers`), `POST /auth/logout`.
